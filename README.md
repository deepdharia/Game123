# 123 — Number Puzzle

A 2048-style number puzzle with **real math**: 1 + 2 = 3, then 3 + 3 = 6, 6 + 6 = 12, doubling all the way to **1536**.

- Single HTML file, zero dependencies, fully offline
- 4 themes (Glass / Paper / Neon / Classic)
- Daily challenge (same board for everyone, every day)
- 5 undos per game, 4×4 / 5×5 / 6×6 boards
- Best score + stats in localStorage
- Monetization hooks ready (rewarded video, remove-ads IAP)

Play: open `index.html` — or the Vercel deployment.
